## 三 · 架構
# 架構原則：**兩種視角**
### 給人看的
清晰的文案與指引，讓參與者一目了然。
```
console.log("Hello Developer!");
```
|||
### 給機器看的
標準的結構化資料與錯誤處理協議。
```
{ "status": "ok", "next_action": "proceed" }
```

# 頁內嵌一個站：**右側視窗**
- 一行 `@embed 網址` 就把站嵌在右邊，跟著簡報一起走。
- 加 `full` 變成標題下方的全寬視窗，加 `lazy` 變成按了才載入。
- 對方站不能設 X-Frame-Options，而且要禁得起沒有儲存空間的環境。
