## 六 · 動手
# 第一步：**開帳號，匯一包素材**
- 到 **larch.ink** 免費註冊，建一個新專案。
- 進「素材」→「素材包」，匯入一包：**午夜頻率**（便利商店、深夜）或**星軌茶館**。 _背景與立繪都在裡面，不扣點數。_
- 順手去市集玩一部別人的，三分鐘就好。 _看完你才知道卡片是怎麼接的。_
十四包內建素材：官方角色、日系獸耳、韓式人物、西遊記、希臘神話，還有七個現成場景包。今晚全部用現成的。
> **動手一（7 分，到第 22 分）。**給四分鐘註冊與匯素材包，三分鐘處理卡關。問「誰還沒進到專案」。

## 六 · 動手
# 第二步：**四種卡排一段**
- **場景卡**換背景、**對話卡**放台詞與立繪、**選擇卡**分兩條線、結局那張勾**結局**。
- 排法：場景 → 對話 → 對話 → 選擇 →（A）對話 → 結局 A ／（B）對話 → 結局 B。
- 排完按**播放**，兩個結局都真的走到。 _角色該退場那張卡把舞台清乾淨，不然他會一直站在那裡。_
照練習一「關東煮前面」排：收銀機關了，阿哲說有件事一直沒講。「說吧」或「明天再說」，兩個結局。十五分鐘。
> **動手二（15 分，到第 37 分）。**自己先排前四張示範（5 分），再給 10 分鐘讓大家排。時間到就往下走。提醒退場那張卡要清舞台。

## 七 · 平台內建的 AI
# 編劇、生圖、配音，**三件**
- **AI 編劇：**白板上按一下，它讀現有的卡往下寫，或從一句話生整段。 _給它限制：一個場景、兩個結局。沒限制它會寫一個你做不完的。_
- **生圖與表情：**角色的識別特徵寫成字（髮型、髮色、一件配件），第二個表情拿第一張當基準生，按一下去背。
- **配音：**每句台詞挑一個內建聲線按生成。 _聲線的中文名不可信，要自己聽一句。_
平常三件都扣松果幣，免費方案每月 20 枚。創好帳號報名挑戰賽，9/20 前不限量（AI 影片除外），所以今晚先報名再開始生。
> **平台 AI 三件（8 分，到第 45 分）。**用我的帳號示範：AI 編劇續寫剛才那段兩張、生一個角色兩個表情、配一句。每件兩分半，不要生第三張圖。

## 八 · 一起做
# 共用白板：**每人一句**
- 我開一個專案，第一張卡只有一句開場。
- 你在聊天室丟一句：**誰、在哪、說了什麼**，最多三十個字，不要寫「然後」。
- 我依序貼成對話卡，每五句加一張選擇卡，兩條線各接下一段。
- 二十句以後按 **AI 編劇**，讓它拿版子上這些卡續寫到結局，當場播。
能開共同編輯的話，抽三個人進來直接在版子上加卡，其他人照樣丟句子。開不了就全部走聊天室，一樣做得出來。
> **共用白板（15 分，到第 60 分）。**開播前決定走哪一種：能開共同編輯就抽三個人進來，開不了全走聊天室。聊天室句子由我貼，一句一卡，貼滿二十句就停。
> **AI 編劇串故事（5 分，到第 65 分）。**按 AI 編劇續寫到結局，直接播。這段是整場最好的部分，不要砍。

## 九 · Agent
# Agent 做的事：**我做白帝城的方式**
- **它會動手。**Claude Code 或 Codex 拿到 Larch 的操作說明後，能直接建專案、上素材、排卡、接線、配音、發佈。
- **白帝城 93 張卡沒有一張是手填的。**劇本寫成一份規格，一支腳本推上版子，版面我後來自己排過，因為我要接手改卡，不接手就讓它排；另一支走查工具把每條路線模擬一遍，抓卡死與走不到的卡。
- **人做的事變成兩件：**寫規格、走一遍抓它演錯的地方。 _版面讓它自己排就好，只有人要接手改卡的時候才值得自己排。填卡片的時間省掉，走查的時間省不掉。_
我把這套整理成一份 larch-vn skill，公開在 GitHub。下週 Agent 就是照它做的。
> **Agent 是什麼（3 分，到第 68 分）。**只講三條，不示範。skill 的 repo 網址講一次就好。

## 六 · 動手
# 第三步：**接上你的 Agent**
- Larch 帳號設定 → 產生 **Agent 操作說明**，權限分項勾（讀取、編輯、素材、AI 生成、預覽、發佈）。
- 把那份說明貼給 Claude Code 或 Codex，接一句：**「用內建素材包『星軌茶館』開一個新專案：打烊前老闆娘問常客要不要換一種茶。一個場景、兩個角色、一個選擇、兩個結局，設好標題畫面，做完發佈，給我市集網址。」**
- 它做的時候你什麼都不用碰。網址來了用手機開，**兩個結局都走到**。 _預覽連結有時效，發佈的市集網址才是永久的。_
跟你剛才手填的那段比：它十分鐘，你十五分鐘。下週整場就是把這一句換成一張解謎規格表。沒裝 Agent 的人今晚看示範，回家照活動頁的步驟接。
> **動手三接 Agent（12 分，到第 80 分）。**示範時操作說明那一頁不入鏡。那一句貼下去就放著讓它跑，這段順便講金鑰紅線；連結來了用手機開兩個結局。有裝的人同步做自己的，題材自選。
